Состав репозитория и архива для сдачи

Два отдельных отчёта Word и PDF передаются преподавателю в комплекте для сдачи.
В открытом репозитории находятся код, проверки и подтверждения выполнения.
lecture03/ содержит 15 примеров лекции, 3 дополнительные демонстрации и 4 СРС.
lab03/ содержит задания 1–6, дополнительное задание и оба учебных примера.
evidence/screenshots/ содержит реальные снимки приложения проверки.
evidence/logs/ содержит неизменённый stdout, stderr, команды и код завершения.
evidence/screenshots.json сопоставляет каждый запуск с его снимками.
lab03/task05_metrics.json содержит фактические измерения 100 000 записей.
lecture03/outputs/benchmark.json содержит измерения 1 000 000 элементов.
В архиве для сдачи Работа_03.bundle содержит переносимый Git-репозиторий
с историей коммитов. Файл bundle не включён в открытый репозиторий.
В архиве для сдачи integrity.json содержит SHA-256 включённых файлов.

Запуск

Откройте PowerShell в распакованной папке Работа_03. Нужен Python 3.10 или новее.
Проверено на CPython 3.12.14, Windows 11. Программы используют стандартную библиотеку.
Если команда python не найдена, замените её на py либо полный путь к Python.

Все пункты лекции:
python -m lecture03 --all

Один пункт лекции:
python -m lecture03 ex01
python -m lecture03 srs1
python -m lecture03 srs2
python -m lecture03 srs3
python -m lecture03 srs4

Доступные идентификаторы: ex01, ex02, ex03, ex04, ex05, ex06, ex07, ex08,
ex09, ex10, ex11, ex12, ex13, ex14, ex15, extra_strings, extra_copy,
extra_pitfalls, srs1, srs2, srs3, srs4.

Лабораторная работа:
python -m lab03.theory interval
python -m lab03.theory group
python -m lab03.task01
python -m lab03.task02
python -m lab03.task03
python -m lab03.task04
python -m lab03.task05
python -m lab03.task06
python -m lab03.extra

У каждого практического запуска есть проверки assert. При успехе программа
завершается с кодом 0. Отрицательные примеры внутри try/except должны вызывать
предусмотренные исключения; это проверка ошибки, а не сбой программы.
Не запускайте демонстрации с параметром -O: он отключает assert.

Повторный запуск srs3 и task05 заново измеряет время и обновляет JSON метрик.
Время зависит от нагрузки компьютера; сравнивать нужно условия и порядок величин.
Числа в отчётах относятся к сохранённым снимкам и журналам первоначального комплекта.

Проверка типов и оформления

python -m pip install -r requirements-dev.txt
python -m mypy lab03
python -m mypy lecture03
python -m ruff check lab03
python -m ruff check lecture03
python quality_checks.py

Последняя команда также проверяет сохранённые журналы 31 практического запуска.
Она не повторяет временные измерения и не меняет таблицы результатов.

Просмотр фактических запусков в локальном приложении

python evidence_viewer.py

Откройте в браузере http://127.0.0.1:8763/?case=lab_task01&run=1
Этот адрес действительно запускает соответствующий Python-модуль.
Для просмотра сохранённого вывода без повторного запуска уберите &run=1.
Идентификаторы остальных запусков находятся в evidence_cases.json.
Для второй части длинного вывода добавьте &part=2.
Приложение слушает только 127.0.0.1. Ctrl+C в PowerShell останавливает его.

Уточнения по заданиям

В СРС 1 исходный список из шести студентов и две группы заданы явно.
Среднее вычисляется арифметическим выражением lambda для этих шести записей,
поскольку условие ограничивает средства sorted, filter, max, min и lambda.
Решение не заявлено как универсальная обработка неизвестного числа групп.

В СРС 3 время list(range(N)) и tuple(range(N)) включает освобождение временного
результата. sys.getsizeof измеряет контейнер без памяти вложенных целых чисел.

MappingProxyType поверхностен. В freeze используется новый словарь и рекурсивное
преобразование содержимого. Представление обычного dict не является ключом dict.

Дополнительный @immutable поддерживает обычные классы с полями, соответствующими
параметрам конструктора; его ограничения и отличия от frozen dataclass описаны
в отчёте и строке документации декоратора.
