ЗАДАНИЕ 2. Изменяемые и устаревающие defaults
1. До: первый журнал после второго вызова = ['вход', 'выход']
   Оба вызова вернули один список: True
   После: старый журнал = ('вход',) ; новый = ('вход', 'выход')
2. До: добавление admin первому изменило роли второго: ['admin', 'student']
   После: Алия = ['reader', 'student'] ; Аскар = ['student']
3. До: кэш после вызова cache_square(4) = {4: 16}
   Изменение скрытого состояния меняет результат: cache_square(4) = 999
   После: результат = 16 ; исходный кэш = {} ; новый = {4: 16}
4. До: время обоих вызовов = 2026-10-17T17:24:29.429188
   Это один объект, сохранённый при def: True
   После: чистая запись = {'text': 'A', 'created': datetime.datetime(2026, 10, 17, 12, 0)}
   make_record_now читает реальные часы: 2026-10-17T17:24:29.439700
Общий кэш может быть намеренным, но скрытое изменяемое состояние нечисто.
Чтение datetime.now тоже нечисто; время передаётся в чистое ядро явно.
ПРОВЕРКИ: четыре исходные ошибки воспроизведены, исправления пройдены.
